# Lokale Schriften

Unveränderte WOFF2-Dateien aus den bereits vorhandenen lokalen POLIRE-Schriftbeständen. Keine Abrufe externer Schriftdienste durch die Demos.

- DM Sans, Barlow Condensed und Cormorant Garamond: SIL Open Font License; die jeweiligen OFL-Dateien liegen bei.
- Satoshi, Switzer und Clash Display: Indian Type Foundry / Fontshare, [ITF Free Font License](https://www.fontshare.com/licenses/itf-ffl). Quellen: [Satoshi](https://www.fontshare.com/fonts/satoshi), [Switzer](https://www.fontshare.com/fonts/switzer), [Clash Display](https://www.fontshare.com/fonts/clash-display).

Die Schriften werden ausschliesslich als eingebettete Website-Schriften verwendet und nicht verändert oder als eigenständiges Schriftprodukt angeboten.
